# Relevance feedback

This entry answers what relevance feedback is, where it began, and how its idea returned in language-model retrieval. It dates the steps from the 1960s to 2026 and separates feedback judged by a user from the automatic form.

## Definition

Ruthven and Lalmas, in their survey, describe relevance feedback as a family of techniques that "improve a user's query and facilitate retrieval of information relevant to a user's information need" [1]. It applies when users find it hard to state a need as a query and instead identify "examples of the kind of documents they require" [1]. Sanderson and Croft describe the 1960s form: documents already retrieved could be marked relevant, and the user's query was automatically adjusted with information taken from them [2]. In pseudo-relevance feedback (PRF), the traditional setup takes the top k documents of an initial retriever as relevant and builds the new query from them [3]. With language models the feedback text may instead be generated by the model [3].

## How it changed

- **1965.** Rocchio's report "Relevance Feedback in Information Retrieval" (Harvard, ISR-9) is Sanderson and Croft's reference for the introduction of relevance feedback in the 1960s, in the ISR reports of Salton's group; they call it "the first (but not the last) use of machine learning in IR" [2]. Era: [The advent](../history/advent.md).
- **2003.** Ruthven and Lalmas survey automatic techniques, where the system changes the query, and interactive ones [1]. Era: [The semantic web and linked data](../history/semantic-web.md).
- **20221220.** HyDE has a language model write a hypothetical document for the query, embeds it, and retrieves real documents near it, without relevance labels (first-party) [4]. Era: [Language models meet retrieval](../history/language-models-meet-retrieval.md).
- **20251124.** Jedidi and Lin note that LLM-based feedback methods "have generally not utilized" classic models such as Rocchio and RM3, and report that HyDE's effectiveness "can be substantially improved" with Rocchio (first-party) [5]. Era: [What has settled since 2023](../history/settled-since-2023.md). No trend page covers it; it is still moving.
- **20260311.** The same authors find feedback from LLM-generated text "the most cost-effective solution", and corpus feedback most useful when a strong first-stage retriever supplies the documents (first-party) [3].

## Where sources disagree

No disagreement found in the sources read. The 2026 findings are conditional, not opposed [3]. How often users give explicit judgements is **unstated**.
