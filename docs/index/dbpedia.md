# DBpedia

DBpedia is a community project that turns the structured parts of Wikipedia into linked data that can be queried with SPARQL. It was one of the first large open graphs of the semantic web era. This entry gives its definition and history; content, size, licence and release activity are on the dataset page.

## Definition

The manuscript of the system report by Lehmann and ten co-authors says the DBpedia community project "extracts structured, multilingual knowledge from Wikipedia" and makes it freely available using Semantic Web and Linked Data standards, with an ontology maintained by the community [1]. The project site calls it "a crowd-sourced community effort to extract structured content" from Wikimedia projects, says its data "is served as Linked Data", and gives access through a SPARQL endpoint [2]. See [linked data](./linked-data.md), [RDF](./rdf.md) and [SPARQL](./sparql.md).

## How it changed

- **2007.** Auer, Bizer, Kobilarov, Lehmann, Cyganiak and Ives publish "DBpedia: A Nucleus for a Web of Open Data" in the Lecture Notes in Computer Science volume "The Semantic Web" (the record gives the year only) [3]. Era: [The semantic web and linked data](../history/semantic-web.md).
- **2015.** The system report appears in Semantic Web 6(2), with 11 authors [4]. The manuscript's abstract (the published text was not read) calls DBpedia a central part of the Linked Open Data cloud and "a connection hub for other data sets" [1]. Era: [Knowledge graphs at scale](../history/knowledge-graphs-at-scale.md).
- **20241217.** The project's yearly recap says "seventeen years ago the first DBpedia dataset was released", which gives 2007 for the first release [5].

## Where sources disagree

The start year. The manuscript of the system report says the project "was started in 2006" [1]. The project site says it "was started in 2007" by Auer and Lehmann at the University of Leipzig [2]. The recap dates the first dataset release to 2007 [5], which fits the site and may fit both if 2006 is the start of work and 2007 the first release; no source read says so. The entry gives both.
