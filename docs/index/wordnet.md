# WordNet

WordNet is a lexical database of English in which words are grouped by meaning and the groups are linked by relations. This entry gives the definition and the history; for what the database holds, its size and its licence, see the dataset page.

## Definition

Its authors call WordNet "an on-line lexical reference system whose design is inspired by current psycholinguistic theories of human lexical memory". English nouns, verbs and adjectives are organized into synonym sets, each representing one underlying lexical concept, and different relations link the sets [1]. Princeton's site describes it as a large lexical database of English whose synonym sets (synsets) are interlinked by conceptual-semantic and lexical relations [2]. It is close to a [semantic network](./semantic-network.md) of word senses.

## How it changed

- **1985.** A group of psychologists and linguists at Princeton University starts the project, first as an aid to search dictionaries conceptually, not only alphabetically [1]. Era: [Knowledge systems](../history/knowledge-systems.md).
- **199308.** The report "Introduction to WordNet: An On-line Lexical Database" is revised; it describes "the state of WordNet as of 1990" [1]. Era: [The Web changes data and search](../history/the-web.md).
- **199511.** Miller's overview "WordNet: a lexical database for English" appears in CACM 38(11) [3]. See the [foundational papers](../papers/foundations.md).
- **2007.** [YAGO](./yago.md) is presented with facts extracted from Wikipedia and "unified with WordNet" [4].
- **20251231.** Princeton's site, in a capture of that date, says Princeton WordNet "is no longer developed", though the database and tools stay freely available, and points to the Open English Wordnet and the Global Wordnet Association [2]. When development stopped is **unstated**.
- **20251231.** The Open English Wordnet, a fork "developed under an open source methodology", releases its 2025 edition; since that release it ships beside Open English Namenet, whose entries derive from [Wikidata](./wikidata.md) [5].
